## 📌 Overview

**CAREBRIDGE** is a clinical pathway intelligence platform that combines:

- 📄 **Medical report analysis**
- 🩺 **Patient-specific clinical pathways**
- 📊 **Population-level pathway analytics**
- 🔎 **Deviation detection**
- 🚦 **Bottleneck detection**
- 🤖 **AI-assisted information**
